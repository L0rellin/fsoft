# 🔹 Создание заявки на изменение

| Код транзакции | **CC31** - Добавить заявку на изменение |
| -------------- | ----------------------------------- |

Запустите транзакцию **CC31** из поля ввода транзакций:
![image_27.png](../Ведение%20основных%20записей%20изменения_images/image_27.png)
Проверьте: тип заявки должен быть выбран «Заявка на изм.», а функция должна быть «Без КоДеблокирования». Если переключатели установлены не так, то нужно их установить как на скриншоте:
![image_61.png](../Ведение%20основных%20записей%20изменения_images/image_61.png)
Вид изменения – укажите 901 а прфиль выберите YQ_ECM01:
![image_52.png](../Ведение%20основных%20записей%20изменения_images/image_52.png)
Далее на клавиатуре нажмите «Enter». На появившемся экране укажите краткий текст заявки на изменение и срок, с которого данное изменение будет действовать (поле «Действительно с»):
![image_8.png](../Ведение%20основных%20записей%20изменения_images/image_8.png)
Нажмите кнопку «Объекты»:
![image_31.png](../Ведение%20основных%20записей%20изменения_images/image_31.png)
Предположим, мы планируем вносить изменения только в рецептуру - в таком случае перейдите на закладку техкарт «ТхКарт»:
![image_62.png](../Ведение%20основных%20записей%20изменения_images/image_62.png)
На этой закладке укажите тип техкарты (Т/Техк) – 2, группу техкарт, для которой будет действовать создаваемая **ОЗИ** (поле «ГрТехкарт»), вид изменения (поле «ВидИзм») – 1 и нажмите Enter:
![image_16.png](../Ведение%20основных%20записей%20изменения_images/image_16.png)
Если планируется с помощью данной **ОЗИ** менять не только рецептуры, но и спецификации, то необходимо перейти на закладку «СпецифМтр» и указать там, для какой конкретно спецификации будет использоваться данная **ОЗИ** и нажать Enter:
![image_46.png](../Ведение%20основных%20записей%20изменения_images/image_46.png)
![Перейдите к заголовку заявки, нажав кнопку  .](../Ведение%20основных%20записей%20изменения_images/image_7.png)
Перейдите к заголовку заявки, нажав кнопку  .
Добавьте текстовый файл блокнот с описанием изменений:
![image_32.png](../Ведение%20основных%20записей%20изменения_images/image_32.png)
В открывшемся окне выберите файл, в котором описаны вносимые изменения.
![image_63.png](../Ведение%20основных%20записей%20изменения_images/image_63.png)
Нажмите открыть.
Примечание – просмотреть прикрепленный файл можно только после создания заявки на изменение. Выберите его в «Списке приложений».
![image_15.png](../Ведение%20основных%20записей%20изменения_images/image_15.png)
Вложить файл можно на любой стадии заявки.
![В заголовке нажмите кнопку «Установить статус»  :](../Ведение%20основных%20записей%20изменения_images/image_39.png)
В заголовке нажмите кнопку «Установить статус»  :
![image_2.png](../Ведение%20основных%20записей%20изменения_images/image_2.png)
На появившемся экране нажмите кнопку «Проверить запрос» :
![image_17.png](../Ведение%20основных%20записей%20изменения_images/image_17.png)
![Нажмите кнопку  :](../Ведение%20основных%20записей%20изменения_images/image_47.png)
Нажмите кнопку  :
![image_71.png](../Ведение%20основных%20записей%20изменения_images/image_71.png)
![Сохраните созданную заявку, нажав на кнопку «Сохранить» :](../Ведение%20основных%20записей%20изменения_images/image_33.png)
Сохраните созданную заявку, нажав на кнопку «Сохранить» :
![image_1.png](../Ведение%20основных%20записей%20изменения_images/image_1.png)
При успешном сохранении **ОЗИ** внизу появится сообщение:
![.](../Ведение%20основных%20записей%20изменения_images/image_18.png)
Заявка была успешно создано, теперь ее необходимо согласовать. Т.е. ответственные сотрудники должны поставить свою подпись под тем, что они согласны с изменениями, которые будут выполняться с помощью данной заявки. Согласовывают заявку уже другие сотрудники – не тот, который занимался созданием заявки.
