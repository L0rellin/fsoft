# 🔍 Проверка и утверждение заявки на изменение

Проверка и утверждение заявки выполняются в транзакции **CC32**.
Укажите номер **ОЗИ** (которая у нас сейчас пока является заявкой), которую нужно согласовать и нажмите Enter:
![image_48.png](../Ведение%20основных%20записей%20изменения_images/image_48.png)
Нажмите на кнопку «Объекты»:
![image_70.png](../Ведение%20основных%20записей%20изменения_images/image_70.png)
Появится экран с перечнем объектов, которые можно будет менять с помощью данной **ОЗИ**. В нашем случае мы указывали на предыдущих шагах, что с помощью данной **ОЗИ** планируем менять одну рецептуру и одну спецификацию, соответсвенно они и видны в списке объектов данной **ОЗИ**:
![image_19.png](../Ведение%20основных%20записей%20изменения_images/image_19.png)
Далее ответственный сотрудник должен определить, какие объекты в итоге разрешено будет менять с помощью данной **ОЗИ**. Предположим, ответсвенным сотрудником принято решение разрешить изменение рецептуры с помощью данной **ОЗИ**, но не разрешить изменение спецификации. Тогда необходимо выделить строку со спецификацией и перейти по меню «Обработать»->«Статус объекта»-> «Изменение невозможно»:
![image_53.png](../Ведение%20основных%20записей%20изменения_images/image_53.png)
Теперь изменение спецификации с помощью данной **ОЗИ** невозможно. О невозможности изменения  спецификации теперь говорит и статус ИЗНВ  (изменение невозможно), который можно увидеть напротив объекта-спецификации, если прокрутить ползунок вправо:
![image_9.png](../Ведение%20основных%20записей%20изменения_images/image_9.png)
Теперь укажем, что изменения для рецептуры возможны. Для этого выделим строку с рецептурой (выделение со строки со спецификацией нужно убрать) и перейдем по меню «Обработать»->«Статус объекта»-> «Изменение возможно»:
![image_34.png](../Ведение%20основных%20записей%20изменения_images/image_34.png)
После этого статус для рецептуры изменился, и стал «ИЗВО» (Изменение возможно):
![image_65.png](../Ведение%20основных%20записей%20изменения_images/image_65.png)
Пока в **ОЗИ** присутстсвуют объекты, которые нельзя изменять с помощью данной **ОЗИ**, мы не сможем согласовать заявку на изменение. Поэтому нужно либо разрешить в итоге изменение спецификации с помощью данной **ОЗИ**, либо удалить объект «Спецификация» из списка объектов. Удалим объект «Спецификация» из списка объектов. Для этого выделим строку со спецификацией, и нажмем кнопку «Удалить»:
![image_20.png](../Ведение%20основных%20записей%20изменения_images/image_20.png)
На появившееся окно с вопросом об удалении, нажмите «Да»:
![image_49.png](../Ведение%20основных%20записей%20изменения_images/image_49.png)
![После этого нужно сохранить **ОЗИ**, нажимаем кнопку .](../Ведение%20основных%20записей%20изменения_images/image_10.png)
После этого нужно сохранить **ОЗИ**, нажимаем кнопку .
Появляется поле с номером нашей **ОЗИ**, нажимаем Enter чтобы снова зайти в нее:
После этого появится окно, в котором пользователь должен ввести свой пароль для входа в **SAP** (под своим логином). Таким образом, своей подписью работник подтверждает, что он согласен преобразовать заявку на изменение в заказ на изменение. В верхней части данного окна можно написать текстовый комментарий для данной заявки на изменение.
![Укажем пароль и нажмем кнопку :](../Ведение%20основных%20записей%20изменения_images/image_35.png)
Укажем пароль и нажмем кнопку :
![image_64.png](../Ведение%20основных%20записей%20изменения_images/image_64.png)
В случае, если данный пользователь имел полномочия на преобразование заявки на изменение в заказ на изменение и если он корректно ввел свой пароль, внизу появляется сообщение об успешном подписании, потом нужно будет нажать кнопку «Дальше»:
![image_72.png](../Ведение%20основных%20записей%20изменения_images/image_72.png)

Сохраните **ОЗИ**, нажав кнопку  . Теперь с помощью  заказа на изменение (который получился путем преобразования заявки на изменение) можно изменять рецептуру.
