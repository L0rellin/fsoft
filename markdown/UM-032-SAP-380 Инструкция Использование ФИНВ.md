# 📌 Назначение

Настоящая инструкция, соответствуют проекту «Формирование данных НУ (налог на прибыль)».  В данной инструкции рассматривается процесс «Использование ФИНВ».

> ℹ️ Перед работой следует внимательно ознакомиться с настоящей инструкцией.

# 🎯 Область применения

В настоящей инструкции описана область применения.

# 🔤 Термины, определения и сокращения

В настоящей процедуре применяют следующие термины и определения:
**SAP** FI - играет ключевую роль в управлении подразделениями предприятия, обеспечивая связь с логистической цепочкой.
Код транзакции - Техническое имя транзакции.
Место возникновения затрат (МВЗ) - Организационная единица внутри контроллинговой единицы, которая представляет собой однозначно выделенный объект отражения затрат.
Балансовая единица (БЕ) - Представляет собой основную организационную единицу с точки зрения финансового учета и отчетности, являющуюся, как правило, самостоятельным юридическим лицом. Представляет собой Компанию с точки зрения налогового законодательства. Наименьшая организационная единица, для которой может вестись самостоятельный комплекс счетов, используемый для составления отчетности для внешних и внутренних пользователей, включая регистрацию всех соответствующих операций и формирование всех вспомогательных документов, входящих в состав финансовой отчетности.
Пользователь - Логин в системе **SAP** идентифицирующий работника Компании.
Транзакция - Комплекс экранных форм, позволяющих выполнять различные бизнес-функции. Транзакция имеет буквенно-цифровой код, используемый для быстрого доступа к экранам через командное поле поиска.
Регистр - Уникальная идентификация специальной бухгалтерской книги.
ЭНУ - Указывает идентификатор объекта налогообложения прибыли, которому присваивается документ по налогу на прибыль.

# 💰 Начисление ФИНВ

- Транзакция **ZFRUPTA****_****FA****_****BALANCE** – Оборотно-сальдовая ведомость по ОС
Проводка начисления ФИНВ выполняется по всем карточкам, в которых заполнен признак «Применение ФИНВ».
Проводку выполнять до прогона амортизации.
![image_18.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_18.png)
Для расчета и формирования проводки начисления ФИНВ на СЭ необходимо проставить флаг ФИНВ
Обязательные данные на СЭ – БЕ / ГОД / ПЕРИОД
Остальные поля – дополнительные критерии выбора, по которым в отчет выводятся данные
![image_15.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_15.png)
![image_13.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_13.png)
Статус:
зеленый – проводка сформирована
желтый  - ФИНВ рассчитан, но не проведен
красный – проведенный и рассчитанный ФИНВ не совпадают по сумме (может возникнуть в случае, когда после формирования проводки по начислению ФИНВ сделали новое поступление на карточку ссылочной датой поступления по которой уже сформирована проводка ФИНВ)
Применение ФИНВ – признак из карточки ОС. Запустив отчет без ограничения по этому признаку на СЭ можно проверить по списку все карточки на предмет корректности заполнения признака
![image_9.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_9.png)
В выделенных строках видно, что в первом ОС статус зеленый, сумма «НУ-ПоступлениеФИНВ» - значит проводка выполнена.
Во второй строке статус желтый, заполнена только сумма «Расчет ФИНВ» - сумма подлежит проводке.
Для выполнения проводки выделяем необходимые строки (или все строки при массовой проводке)
![image_4.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_4.png)
После чего нажимаем пиктограмму «Проводка финв»
![В появившемся окне заполняем дату, которой необходимо сформировать проводку](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_1.png)
По карточкам сформируется проводка ВД Z15 (либо Z17 при отрицательной сумме поступления). Корреспонденция: Дт 9901996804	ПостФИНВ ТехНУ /  Кт счет учета стоимости ОС.
# 🔄 Сторно ФИНВ

При перемещении между карточками необходимо выполнить сторно начисленного ФИНВ – транзакция **AB****08 **(если перемещение периодом отличным от периода начисления ФИНВ, то причина сторно 04)
Начисление ФИНВ по новой карточке будет зависеть от признаков ОС – подходит ли по параметрам ОС для ФИНВ.
При сторно ФИНВ по карточке с который выполняется перемещение на следующем шаге – использование ФИНВ, проведется корректировка суммы использования данного ФИНВ с признаком Красного сторно.
# ♻️ Восстановление ФИНВ

При выбытии ОС ранее чем через 5 лет после начисления ФИНВ вычет подлежит восстановлению.
Транзакция **ABGL** Вид движения Z16 / Z18 (соответствуют ВД начисления Z15 / Z17)

# ✅ Использование ФИНВ

Транзакция ZTAX_PROFIT_POST – Использование ФИНВ
![image_7.png](./UM-032-SAP-380%20Инструкция%20Использование%20ФИНВ_images/image_7.png)
🖼️ Рис. 1.1. Селекционный экран
| **Название поля** | **Обязательно для заполнения ** | **Данные** |
| ----------------------- | ------------------------------- | ------------------------ |
| БЕ | Да | Балансовая единица |
| Финансовый год | Да | Отчетный год |
| Месяц финансового года | Да | Отчетный период |
| Период | Да | Данные за прошлые месяцы |
| Индекс: документ сторно | Нет |  |
| Расчет | Нет |  |
| Проводка | Нет |  |

При заполнении СЭ и запуске отчета выводит данные по всем карточкам ОС, области N1 (Налоговый регистр) и видом движения Z15 / Z17 (Начисление ФИНВ), по которым выполнено начисление ФИНВ транзакцией ZFRUPTA_FA_BALANCE.
Поле «Период» заполняется количесвом месяцев за которые необходимо вывести данные. Например, если заполнить поле «Период» значением 60, то выведет данные за последние 5 лет.
При пустов флаге Документ сторно выведутся только несторнированные документы начислений.
При заполненном флаге Документ сторно выведутся в том числе сторнированные докуманты и документы сторно с заполнением причины сторно.
Флаг расчет – выводит данные предельной нормы ФИНВ в разрезе списания с ОС (тестовый режим)
Флаг проводка – активирует пиктограмму «Провести документ» (продуктивный режим)
