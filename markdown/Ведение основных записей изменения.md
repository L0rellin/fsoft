# 📘 Ведение основных записей изменения

## Назначение

Данная инструкция описывает бизнес-процесс создания, изменения, просмотра основной записи изменений (**ОЗИ**). Основная запись изменений создается сначала в виде заявки на изменение. Далее эта заявка проверяется и утверждается (или отклоняется) различными ответственными лицами. После утверждения заявка преобразовывается в заказ. Далее заказ деблокируется ответственным лицом – после этого **ОЗИ** можно использовать для изменения рецептур и спецификаций.
**ОЗИ** используется для изменения норм для операций рецептуры, добавления операций, изменения норм расхода в спецификации материала с определенного срока или на определенный период. В **ОЗИ** указывается срок начала изменения, после этого производятся соответствующие изменения в рецептуре с указанием номера изменения. В период действия изменения при планировании, при списании будут учитываться нормы для рецептуры и спецификации, привязанные к данному изменению (попадающему в период). При использовании службы изменений при изменении рецептуры не создается новая версия рецептуры. Вместо этого в системе создается две копии данных: первая копия с данными рецептуры до изменения, вторая копия с данными рецептуры после изменения.
## Область применения

Описанные в операционной инструкции шаги необходимы для создания, изменения, просмотра основной записи изменений.
