# ✅ Деблокирование заказа на изменение

Введите транзакцию СС32 в поле для ввода транзакций и нажмите Enter:
![image_4.png](../Ведение%20основных%20записей%20изменения_images/image_4.png)
В поле «Номер изменения» введите номер заказа на изменение (номер **ОЗИ**), который будем деблокировать, и нажмите Enter:
![image_22.png](../Ведение%20основных%20записей%20изменения_images/image_22.png)
Нажмите кнопку «Объекты», чтобы перейти в списку объектов (у нас в списке объектов будет только ресуптура – спецификацию из списка объектов мы удалили ранее):
![image_50.png](../Ведение%20основных%20записей%20изменения_images/image_50.png)
![Выделите строку с рецептурой и нажмите кнопку «ПодрРакурс»  :](../Ведение%20основных%20записей%20изменения_images/image_66.png)
Выделите строку с рецептурой и нажмите кнопку «ПодрРакурс»  :
![image_28.png](../Ведение%20основных%20записей%20изменения_images/image_28.png)
Нажмите кнопку «Установить статус»:
![image_55.png](../Ведение%20основных%20записей%20изменения_images/image_55.png)
Нажмите «Завершить изменение»:
![image_11.png](../Ведение%20основных%20записей%20изменения_images/image_11.png)
Нажмите «Деблокир. изменение»:
![image_41.png](../Ведение%20основных%20записей%20изменения_images/image_41.png)
Нажмите кнопку «Дальше»:
![image_67.png](../Ведение%20основных%20записей%20изменения_images/image_67.png)
Мы деблокировали  **ОЗИ** на уровне одного объекта (выбранной рецептуры), но для того, чтобы изменения со ссылкой на данную **ОЗИ** вступили в силу, необходимо деблокировать **ОЗИ** целиком (на уровне заголовка). Для этого перейдите в заголовок **ОЗИ**, нажав кнопку «Заголовок изменений»:
![image_23.png](../Ведение%20основных%20записей%20изменения_images/image_23.png)
![Нажмите на кнопку «Устновить статус» :](../Ведение%20основных%20записей%20изменения_images/image_51.png)
Нажмите на кнопку «Устновить статус» :
![image_12.png](../Ведение%20основных%20записей%20изменения_images/image_12.png)
На появившемся экране нажмите «Закрыть заказ»:
![image_37.png](../Ведение%20основных%20записей%20изменения_images/image_37.png)
Нажмите «Деблокировать заказ»:
![image_56.png](../Ведение%20основных%20записей%20изменения_images/image_56.png)
Нажмите кнопку «Дальше»
![image_75.png](../Ведение%20основных%20записей%20изменения_images/image_75.png)
![Нажмите  для сохранения деблокированной **ОЗИ**. Теперь изменения, сделанные на основе данной **ОЗИ**, вступили в силу, и эти изменения можно увидеть в системе.](../Ведение%20основных%20записей%20изменения_images/image_42.png)
Нажмите  для сохранения деблокированной **ОЗИ**. Теперь изменения, сделанные на основе данной **ОЗИ**, вступили в силу, и эти изменения можно увидеть в системе.
