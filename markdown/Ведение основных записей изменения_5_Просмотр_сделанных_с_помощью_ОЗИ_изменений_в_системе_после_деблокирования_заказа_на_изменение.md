# 📝 Просмотр изменений после деблокирования заказа на изменение

Прверим изменения, которые  были сделаны в пункте 2. Для этого в поле ввода транзакций запустите транзакцию **C203** (Просмотр рецептуры):
![image_5.png](../Ведение%20основных%20записей%20изменения_images/image_5.png)
В поле «Группа рецептур» укажите рецептуру, для которой будем проверять сделанные изменения.  В поле «Контрольная дата»  стоит актуальная дата, на которую просматривается рецептура. По умолчанию системой проставляется текущая дата, но ее можно поменять. Пока менять не будем, посмотрим, как выглядит заголовок указанной рецептуры на дату 10.11.2014:
![image_24.png](../Ведение%20основных%20записей%20изменения_images/image_24.png)
Нажимаем кнопку «Заголовок рецептуры», чтобы попасть сразу в заголовок рецептуры:
![image_57.png](../Ведение%20основных%20записей%20изменения_images/image_57.png)
В поле «Базисное кол-во» можно увидеть, что оно равно 634,200 ТШТ:
![image_74.png](../Ведение%20основных%20записей%20изменения_images/image_74.png)
Это новое кол-во, которое ввели в ходе изменения. Старое значение было 635,500 ТШТ (См. пункт 3 данной инструкции). Т.е на дату 10.11.2014 в рецептуре действует уже новое базисное кол-во.
В созданной **ОЗИ** проставлен срок действия 01.11.2014. Т.е. до этой даты базисное кол-во должно оставаться старым -  635,500 ТШТ. Проверим это экспериментально.
В поле ввода транзакций введите **C203**:
![image_5.png](../Ведение%20основных%20записей%20изменения_images/image_5.png)
На первом экране транзакции С202 в поле «Группа рецептур» укажем ту же группу, что и раньше, а в поле «Контрольная дата» укажем дату, предшествующию дате  01.11.2014,, например 30.10.2014. После этого нажмем кнопку «Заголовок рецептуры»:
![image_38.png](../Ведение%20основных%20записей%20изменения_images/image_38.png)
В заголовке рецептуры можно увидеть, что в поле «Базисное кол-во» стоит старое значение 635,500 ТШТ:
![image_6.png](../Ведение%20основных%20записей%20изменения_images/image_6.png)
Т.е. действительно, до даты 01.11.2014 в рецептуре действует старое базисное кол-во, а начиная с даты 01.11.2014 (включительно) действует новое базисное кол-во.
